# 09: 백업 내보내기, 가져오기, 배너

**What to build:** 설정 화면에서 "백업"을 누르면 모든 데이터가 JSON 파일로 만들어져 iPhone 공유 시트가 열리고, iCloud Drive나 파일 앱에 저장할 수 있다. "가져오기"로 백업 파일을 고르면 "현재 데이터가 모두 교체됩니다" 확인 후 전체 교체되고, 잘못된 파일이면 오류 안내와 함께 기존 데이터가 그대로 남는다. 기록이 있는데 백업한 적이 없거나 마지막 백업이 7일을 넘었으면 오늘 화면에 "마지막 백업 N일 전" 배너가 뜬다. 배경 결정은 ADR 0001.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 오늘 화면에서 설정 화면으로 이동할 수 있다
- [ ] WorkoutLog가 내보내기를 제공한다: 형식 버전, 내보낸 시각, 종목 목록, 세트 목록을 담은 JSON
- [ ] 내보내기는 Web Share API로 파일을 공유하고, 지원되지 않으면 파일 다운로드로 대체한다
- [ ] 내보내기에 성공하면 마지막 백업 시각이 저장된다
- [ ] WorkoutLog가 가져오기를 제공한다: 형식을 검증한 뒤 하나의 트랜잭션으로 전체 교체하고, 검증 실패 시 기존 데이터를 건드리지 않는다
- [ ] 가져오기 전에 확인 창이 뜨고, 실패하면 오류 안내가 보인다
- [ ] 세트가 1개 이상이고, 백업한 적이 없거나 마지막 백업이 7일을 넘었으면 오늘 화면에 배너가 뜨며, 배너에서 바로 백업할 수 있다
- [ ] 테스트: 내보낸 JSON을 빈 DB에 가져오면 모든 조회 결과가 같음, 가져오기가 기존 데이터를 교체함, 잘못된 JSON(형식 오류, 버전 불일치, 필드 누락)은 거부되고 기존 데이터 유지
- [ ] 테스트와 빌드가 통과한다
