# 04: 종목 선택 — 최근 순, 검색, 즉석 추가

**What to build:** 오늘 화면에서 "종목 추가"를 누르면 종목 선택 화면이 열리고, 최근에 한 종목이 위에 온다. 위쪽 검색 칸에 입력하면 목록이 걸러지고, 일치하는 종목이 없으면 "'OO' 새 종목으로 추가"를 눌러 그 자리에서 만들고 바로 기록 화면으로 들어간다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] WorkoutLog의 종목 목록이 종목별 가장 최근 세트 기록 시각 순으로 정렬되고, 세트가 없는 종목은 뒤에 온다
- [ ] 이름 검색(부분 일치, 대소문자/앞뒤 공백 무시)이 동작한다
- [ ] 검색 결과가 없으면 "'OO' 새 종목으로 추가"가 보이고, 누르면 종목이 생기고 기록 화면으로 이동한다
- [ ] 같은 이름(앞뒤 공백 무시)의 종목은 중복으로 만들 수 없다
- [ ] 종목을 탭하면 그 종목의 기록 화면으로 이동한다
- [ ] 테스트: 최근 사용 순 정렬, 세트 없는 종목 위치, 검색, 중복 이름 거부
- [ ] 테스트와 빌드가 통과한다
