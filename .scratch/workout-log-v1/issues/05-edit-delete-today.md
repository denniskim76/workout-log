# 05: 오늘 세트 수정과 삭제

**What to build:** 오늘 화면이나 기록 화면에서 세트를 탭하면 무게와 횟수를 고치거나 세트를 삭제할 수 있다. 오늘 세션의 세트를 모두 지우면 오늘 세션이 사라지고 빈 상태 안내가 보인다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] WorkoutLog가 세트 수정(무게, 횟수)과 삭제를 제공하며, 수정에도 같은 입력 검증이 적용된다
- [ ] 세트를 탭하면 수정/삭제 UI가 열리고, 저장하면 오늘 화면과 기록 화면에 즉시 반영된다
- [ ] 세션의 세트를 모두 삭제하면 그 세션이 조회되지 않는다
- [ ] 세트를 수정하면 미리 채우기와 지난 기록(03이 완료된 경우)도 수정된 값을 따른다
- [ ] 테스트: 수정 결과 조회, 삭제 후 세션 조회, 마지막 세트 삭제 시 빈 세션 없음, 잘못된 수정값 거부
- [ ] 테스트와 빌드가 통과한다
