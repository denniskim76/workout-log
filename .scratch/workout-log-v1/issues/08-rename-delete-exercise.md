# 08: 종목 이름 변경과 삭제

**What to build:** 종목 선택 화면에서 종목 이름을 바꾸면 과거 기록에도 새 이름이 보인다. 종목을 삭제하면 "세트 N개도 함께 삭제됩니다" 확인 창이 뜨고, 확인하면 그 종목과 모든 세트가 지워진다. 그 결과 세트가 0개가 된 세션은 사라진다.

**Blocked by:** 04

**Status:** ready-for-agent

- [x] 종목 선택 화면에서 종목의 이름 변경과 삭제에 접근할 수 있다(실수로 누르기 어려운 위치)
- [x] 이름 변경 시 중복 이름은 거부되고, 바꾸면 오늘/과거 세션과 지난 기록에 새 이름이 표시된다
- [x] WorkoutLog가 종목의 세트 개수를 제공하고, 삭제 확인 창에 그 개수가 표시된다
- [x] 삭제하면 종목과 그 종목의 모든 세트가 하나의 트랜잭션으로 지워진다
- [x] 테스트: 이름 변경 후 과거 세션 조회에 새 이름, 삭제 후 모든 세션에서 그 종목 세트가 사라지고 빈 세션도 사라짐, 중복 이름 거부
- [x] 테스트와 빌드가 통과한다

## Comments

- **공개 메서드**(`exercises.ts`): `renameExercise(id, name)`, `countSets(exerciseId)`, `deleteExercise(id)`.
- **이름 변경**: 추가와 같은 규칙으로 앞뒤 공백을 빼고 저장하며, 다른 종목과 이름이 같으면 `DuplicateExerciseNameError`를 던진다(대소문자 구분). 자기 이름 그대로(공백만 다른 경우 포함)로 바꾸는 것은 허용한다. 검사와 변경은 한 트랜잭션이다. 세트는 종목 id로 참조하므로 세션 조회는 바꿀 필요가 없었다.
- **삭제**: 세트와 종목을 `exercises`, `sets` 두 테이블에 걸친 한 트랜잭션으로 지운다. 세션은 세트에서 계산하므로 세트가 0개가 된 운동일은 별도 처리 없이 조회되지 않는다(`getSession`이 null). 세션 목록 조회는 아직 없어서 테스트는 `getSession`으로 확인했다.
- **세트 개수**: 모든 운동일에 걸친 그 종목의 세트 수다. 삭제 확인 창에서는 세트가 1개 이상일 때만 "세트 N개도 함께 삭제됩니다"를 보여 주고, 세트가 없는 종목도 삭제 전에 확인은 받는다.
- **화면**: 종목 선택 화면 제목 옆 "편집" 버튼으로 편집 모드를 켜야 각 종목에 "이름 변경"/"삭제" 버튼이 나온다(실수 방지). 편집 모드에서는 종목을 눌러도 기록 화면으로 가지 않는다. 이름 변경은 그 자리의 입력 칸, 삭제 확인은 `window.confirm` 대신 그 자리에 펼쳐지는 확인 카드(취소/삭제)로 했다. 새 컴포넌트 `ExerciseEditRow.tsx`와 그 스타일 `ExerciseEditRow.css`를 따로 두어 병렬 티켓과 겹치는 파일(`index.css` 등)을 건드리지 않았다.
- **UI 확인**: 빌드와 타입 검사는 통과했지만 브라우저에서 직접 눌러 확인하지는 않았다.
