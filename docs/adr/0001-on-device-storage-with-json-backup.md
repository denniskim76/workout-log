# 서버 없이 기기 안에만 저장하고 JSON 백업으로 보완한다

혼자 쓰는 기록 앱이고, 헬스장 지하처럼 신호가 약한 곳에서도 세트 직후 즉시 기록되어야 한다. 그래서 모든 데이터를 휴대폰 브라우저의 IndexedDB에만 저장하고 서버, 로그인, 동기화는 두지 않는다. 브라우저 데이터가 지워지면 기록이 사라지는 위험은 JSON 파일 내보내기/가져오기로 보완하며, 이 기능은 첫 버전부터 포함한다.

## Considered Options

- **클라우드 저장(Supabase, Firebase 등)**: 기기 변경과 PC 열람이 쉽지만 로그인, 서버 설정, 오프라인 동기화가 붙는다. 사용자가 한 명이라 얻는 것보다 비용이 크다고 판단했다.

## Consequences

- iPhone(Safari)에서는 홈 화면에 추가한 PWA로 써야 저장소가 안정적으로 유지된다. 사용자에게 백업을 주기적으로 상기시켜야 한다.
- 나중에 동기화를 추가하려면 기존 기기 데이터를 서버로 옮기는 이전 작업이 필요하다.
